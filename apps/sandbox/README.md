# CADS Symbol Fill Sandbox

Parametric preview of the CodeAI mark as a modular grid of live CADS components. Occupancy follows the symbol paths; each row-run is fully covered (no interior holes).

```bash
pnpm --filter @codeai/cads-sandbox dev
# → http://localhost:3200
```

DialKit:

- **Stage** — theme (light/dark), surface, chrome, outline, glow
- **Grid** — columns (default 16), gap, inset, swatch ratio, control size, component toggles, reshuffle
