For any FA Font files you add here (or sync via an API token), you'll need to install the same font files on your computer. Otherwise, they will show up in the icon picker, but won't render on the canvas when you try to insert them. Similarly, if you sync or add new font files to the plugin, make sure you update the font files on your computer as well.
